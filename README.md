# Blood Moon — Explorador Lunar

Aplicação web educativa para explorar as oito fases da Lua, simular o ciclo lunar e testar conhecimentos em um quiz interativo.

## Funcionalidades
- Oito fases lunares selecionáveis, com ilustração, descrição e iluminação aproximada.
- Simulador didático de aproximadamente 29,5 dias com iniciar, pausar, continuar, reiniciar e controle de velocidade.
- Quiz com oito questões, quatro alternativas, feedback, pontuação e nova tentativa.
- Interface responsiva, feita com HTML, CSS e JavaScript puro.

## Executar
Abra `index.html` no navegador. Opcionalmente, execute `python -m http.server 8000` e acesse `http://localhost:8000`.

## Arquivos
- `index.html`: estrutura da aplicação.
- `style.css`: tema espacial responsivo.
- `script.js`: fases, simulador e quiz.
- `docs/validacao.md`: plano de testes RF01–RF12.

## GitHub Pages
Em Settings → Pages, escolha Deploy from a branch, branch `main`, pasta `/ (root)` e salve.
